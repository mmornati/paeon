# Site (website/, docs theme, videos)

Scope: the public site on GitHub Pages: a landing page (`website/`), the MkDocs documentation
under `/docs/`, and three narrated canvas videos. Mode: Persuade for the landing, Read for docs.

Audience and job: someone who runs a self-hosted server and already gets alerts. They must
understand in one screen that models only think, a person says Go, and plain code acts; then
start the quickstart. Proof on hand: the real console (synthetic data), the README's facts.
Constraints: every example is fictional and says so; alpha status and "not yet proven in use"
stay visible; no invented numbers, customers or claims.

## Direction contract

THESIS: A launch-day status board. Each station of Paeon reports in turn, and the last row holds
on YOU: nothing leaves the pad until you say Go. Refused: the dark product hero with a console
screenshot over a grid of icon feature cards.

OWN-WORLD: a deep navy board (#0b1626) with slightly lighter panels, chalk-white condensed
capitals (Barlow Condensed) for station names, tabular times, and lit status cells: go-green
(#2fd07b) GO, amber (#ffb000) HOLD, abort red (#ff4d4f) NO-GO. Violet marks what a model said,
as in the console. Hairline rules between rows, square lamp cells, a striped guard over the one
switch that acts.

STORY: the visitor watches a poll run on a fictional incident, sees it stop at YOU, lifts the
guard and says Go, and sees the executor apply and verify. They believe the line between
thinking and doing is real, and open the quickstart.

FIRST VIEWPORT: left, five columns: the headline "Nothing leaves the pad until you say Go.",
one paragraph, a solid amber Quickstart button and an outlined "Watch the flow". Right, seven
columns: the status board at full height, rows RECORD, CORRELATE, TRIAGE, INVESTIGATE, PLAN
lighting GO one by one with their finding, then YOU on amber HOLD beside the guarded switch.

FORM: flight-director Go/No-go poll; position 1 of my ordered list (the user took the pick card
over the assigned direction); seed 324f2423. Signature interaction: the two-step guarded Go
switch (lift the guard, then press), after which the EXECUTOR rows run apply and verify.
Motion grammar: rows report in sequence like a poll being called; nothing else moves. Code-led:
the image key had no credit, so no comp exists.
